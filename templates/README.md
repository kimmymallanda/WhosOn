# Templates for the captain's setup page

- `roster_template.csv`: one row per player. **Name** and **Email** are required. Mobile, Level Flight (like AA-3) and Preferred Side (ad, deuce or either) are optional. The columns can be in any order and the headings are matched loosely ("Cell" works for Mobile).
- `schedule_template.csv`: one row per match. **Date**, **Opponent** and **Home/Away** are required. Facility is optional.

Excel files (.xlsx) work too, with the same headings. All the names and addresses here are made up.
